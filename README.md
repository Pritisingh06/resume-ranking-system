# 🤖 AI Resume Ranking System

## 📌 Overview
This project is an AI-based Resume Ranking System that matches resumes with job descriptions using Natural Language Processing (NLP) techniques. It helps recruiters shortlist candidates efficiently and assists job seekers in improving their resumes.

---

## 🚀 Features
- 📄 Upload resume (PDF format)
- 🧠 Job description matching using NLP
- 📊 Match score calculation using TF-IDF & Cosine Similarity
- 🧩 Skill matching and gap analysis
- 🌐 User-friendly Flask web interface

---

## 🛠️ Tech Stack
- Python
- Flask
- Scikit-learn
- NLP (TF-IDF)
- HTML, CSS
- PyPDF2

---

## ⚙️ How It Works
1. User enters a job description  
2. Uploads a resume (PDF)  
3. System extracts text from resume  
4. Applies TF-IDF vectorization  
5. Calculates similarity using cosine similarity  
6. Displays match score and relevant skills
